# Chat Comics

An OBS Browser Source overlay that turns stream chat into a live comic strip. Every chatter gets their own
fuzzy little monster, replies put both monsters in the same panel, and faces change with the mood of the message.

Live at [comics.ixitxachitl.com](https://comics.ixitxachitl.com). Setup guide:
[tools/chat-comics](https://www.ixitxachitl.com/tools/chat-comics.html).
